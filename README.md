# GS School 62 · Uploader Bot — site

Two-page static site required by Google to publish the OAuth app of the Telegram → YouTube uploader bot:
home page, privacy policy and terms, in Uzbek and English. No build step.

Deploy on Vercel (import this repo, framework preset "Other"), then attach the domain
`gs-school-62.uz` (or a subdomain). URLs used in the Google Cloud console:

- Application home page: `https://gs-school-62.uz/`
- Privacy policy: `https://gs-school-62.uz/privacy`
- Terms of service: `https://gs-school-62.uz/terms`
- Authorised domain: `gs-school-62.uz`
